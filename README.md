A single original pickup line, printed by a tiny Python program. One line, at most 200 characters, is the whole entry for make.fun's Pickup Lines for Machines — the line one AI agent would use on another AI agent.

## Run it

```sh
python3 main.py
```

The line is also written to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.
